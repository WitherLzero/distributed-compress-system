# 03 — codec 接口返回值与序列化契约修订

- **Status**: needs-triage
- **依据**: `meeting/见识星球 昕棋 软件研发实习第4课.md`（2026-11-14），时间戳 19:57–22:28、34:04–38:20、29:39–30:16

## What to change

1. **返回值契约**：压缩/解压接口当前同时返回 `n` 与 `outLen` 且二者相同，语义混乱。改为：返回错误码（0 = 成功），调用方先判返回值，成功后再读 `outLen` 出参。（24:44–25:40）
2. **参数类型**：输入输出 `uint8_t*` 业界少见，改 `char*`。（20:24、22:12）
3. **OutCap 参数**：输出缓冲已在外部分配，`OutCap` 疑似无用——确认调用方后去掉。（21:29–22:03）
4. **参数约定（经验项，可选）**：评估"输入传引用、输出传指针"约定，一眼区分可动/不可动参数。（34:04）
5. **memset 契约**：序列化 `memcpy` 前必须保证输出 buffer 已清零（malloc 内存不保证干净）——在函数注释写明调用契约，单测覆盖。（36:28–38:07）
6. **temp 文件目录**：临时文件不应与最终文件同路径拼接，统一放独立 temp 目录——落点 `atomic_replacer.cpp`（写盘纪律唯一落点）。（29:39–30:16）

## 约定

- 代码在 WSL 侧 `src/common/`，走 `feat/` 分支；agent 经 `wsl` 工具操作。
- 纯逻辑改动必须带 gtest 单测更新，`ctest` 全绿。
- 第 4/5 项为约定/契约固化，不强制改接口形状——与学员确认后再动。

## Acceptance

- [ ] 压缩/解压返回值改为错误码 + outLen，调用点全部适配

- [ ] 序列化契约（memset 前置）写入注释并被单测覆盖
- [ ] temp 文件统一入独立目录，atomic_replacer 单测更新
- [ ] `ctest` 一键全绿，`-Wall -Wextra` 无警告
