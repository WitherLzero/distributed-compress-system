# 06: codec + 文件头读写 + 单测

**Parent**: 03 — 工程脚手架与公共/基础类

**What to build**: 压缩系统的两个纯逻辑叶子：统一编解码封装（LZ4 浅压 / LZMA 深压同一调用面），以及块级自包含文件头的写入与读回（布局按已定稿决策：128 字节定长头 + 每切片 8 字节条目，偏移量不存、由顺序与定长推导；压缩输出缓冲按 2× 原始大小纪律预留）。两者都是后续所有数据路径依赖的稳定叶子，本票只到"正确读写 + 可验证"，不接任何 IO 或网络。

**Blocked by**: 04（构建链与测试基建）。

**Status**: ready-for-agent

- [x] 统一编解码封装：压缩级别 → 算法选择，压缩/解压同一调用面；输出缓冲按 2× 原始大小申请（不可压膨胀防越界）
- [x] LZ4 与 LZMA 各自 round-trip 单测：随机输入与半压缩（如重复文本）输入，解压后逐字节相等
- [x] 文件头写入/读回一致性单测：构造头 + 条目序列 → 序列化为字节区 → 从字节区解析 → 逐字段相等
- [x] 布局符合已定稿决策：定长头 128B（含魔数、格式版本、算法、切片数、原始块大小），条目 8B（压后长度 + 校验值），合计不超 4KB 一页预算
- [x] ctest 通过
