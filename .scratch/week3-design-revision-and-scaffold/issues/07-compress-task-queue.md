# 07: CompressTaskQueue + 有界性单测

**Parent**: 03 — 工程脚手架与公共/基础类

**What to build**: 扫描线程与压缩执行线程之间的候选任务队列：header-only、有界、线程安全。生产端（冷却扫描）push，消费端（压缩执行）pop；满时不无限堆积，空时不忙等空转。这是系统内第一个跨线程同步原语，行为纯逻辑、可单测。

**Blocked by**: 04（构建链与测试基建）。

**Status**: ready-for-agent

- [ ] 有界行为单测：压满后 push 返回失败/拒绝语义，不溢出、不丢已有元素
- [ ] 并发单测：多生产者/单消费者线程压入取出全部元素，无丢失无重复
- [ ] ctest 通过
